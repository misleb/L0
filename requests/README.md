# Incoming feature requests

Requests from projects that use L0 land here, either copied by
`l0 submit` when `L0_HOME` points at this repository, or pasted in by hand.

They are evidence, not decisions. Triage each one with the `l0-evolve`
skill, judging it against the standard its author was held to in
`lib/skills/l0-limits/SKILL.md`.

Requests are kept after triage, accepted or not. A rejected request is worth
as much as an accepted one: it records a limitation someone actually hit and
the reason the language did not change, which is exactly the argument that
would otherwise be relitigated a year later.

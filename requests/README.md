# Incoming requests

Requests from projects that use L0 land here, either copied by
`l0 submit` when `L0_HOME` points at this repository, or pasted in by hand.

There are two kinds:

- **Language requests**, judged with the `l0-evolve` skill against
  `lib/skills/l0-limits/SKILL.md`. Accepted or not, they are kept: a
  rejected one records a limitation someone actually hit and the reason the
  language did not change.
- **Skill notes** (`Kind: skill`), judged with the `l0-evolve` skill's
  section on skill notes. These change what `l0 init` copies, not the spec.
  Merge the part that would help any L0 project into `lib/skills/`; send
  back anything that is project-specific.

They are evidence, not decisions.

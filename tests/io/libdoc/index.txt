== prelude: Lists and arrays of any type, Option, Result, Map, and lists of bytes: building output, comparing and sorting, decimal and hexadecimal numbers, slicing lines and words, word tables, and character classes.
  (rev_onto T) ((xs (list T)) (acc (list T))) (list T)
      xs reversed, in front of acc, for a list of any type: (rev_onto "ab" "cd") is "bacd".
  (rev T) ((xs (list T))) (list T)
      xs reversed, for a list of any type.
  (append T) ((xs (list T)) (ys (list T))) (list T)
      xs followed by ys, for lists of any type.
  (length T) ((xs (list T))) int
      The number of elements of xs, a list of any type.
  (any_eq T) ((x T) (xs (list T))) bool
      Whether x is one of xs, by eq, for a list of any type.
  (index_of T) ((x T) (xs (list T))) int
      The position of the first element of xs that is x, by eq, counting from 0, or -1 if there is none, for a list of any type.
  (find_by K T) ((key (fn (T) K)) (k K) (xs (list T))) (Option T)
      The first element of xs whose key is k, by eq, or None, for a list of any type and a key of any type.
  (min T) ((a T) (b T)) T
      The lesser of a and b by compare, for values of any type, and a when they are the same.
  (max T) ((a T) (b T)) T
      The greater of a and b by compare, for values of any type, and a when they are the same.
  (sort T) ((xs (list T))) (list T)
      xs in the order compare gives, ascending, for a list of any type: (sort "cab") is "abc".
  (array_resize T) ((a (array T)) (n int) (fill T)) (array T)
      An array of n elements of any type: the first n of a, followed by copies of fill if a has fewer.
  (data (Option T) (None) (Some T))
      A value that may be missing: (Some x), or (None).
  (data (Result T E) (Ok T) (Err E))
      The outcome of something that can fail: (Ok x), or (Err e) saying why.
  (data (Map K V) (MapEmpty) (MapTable (array int) (array (MapSlot K V)) int))
      A map from keys of type K to values of type V, written once for every type: keys are compared with eq and placed by hash, so any value can be a key.
  (map_put K V) ((m (Map K V)) (k K) (v V)) (Map K V)
      m with k mapped to v, replacing any value k had.
  (map_get K V) ((m (Map K V)) (k K)) (Option V)
      The value k maps to in m, or (None) if it has none.
  (map_has K V) ((m (Map K V)) (k K)) bool
      Whether k has a value in m.
  (map_size K V) ((m (Map K V))) int
      How many keys m maps to values.
  (map_remove K V) ((m (Map K V)) (k K)) (Map K V)
      m without k, or m as it was if k has no value.
  (map_keys K V) ((m (Map K V))) (list K)
      Every key m has, each once.
  (map_values K V) ((m (Map K V))) (list V)
      Every value m has, in the same order as map_keys gives their keys.
  (data (MapPair K V) (MapPair K V))
      A key and the value a map gives it, as map_pairs lists them.
  (map_pairs K V) ((m (Map K V))) (list (MapPair K V))
      Every key m has, each with its value, sorted by key in compare's order.
  (map_eq K V) ((a (Map K V)) (b (Map K V))) bool
      Whether a and b hold the same keys, each mapped to the same value.
  push ((chunk (list int)) (acc (list int))) (list int)
      Pushes chunk onto a reversed accumulator: acc with chunk's bytes in front, last byte first.
  list_eq ((xs (list int)) (ys (list int))) bool
      Whether xs and ys hold the same bytes in the same order, as (eq xs ys) says.
  digits ((n int)) (list int)
      n in decimal, with a leading - if negative: (digits -42) is "-42".
  hex_digits ((n int) (width int)) (list int)
      n in lowercase hexadecimal, padded with zeros to at least width digits: (hex_digits 255 4) is "00ff", and (hex_digits 0 0) is "0".
  drop_n ((xs (list int)) (n int)) (list int)
      xs without its first n elements, or empty if it has fewer.
  starts_with ((s (list int)) (prefix (list int))) bool
      Whether s begins with prefix.
  take_line ((s (list int))) (list int)
      s up to but not including its first newline, or all of s if it has none.
  drop_line ((s (list int))) (list int)
      Everything after the first newline of s, or empty if it has none.
  skip_digits ((s (list int))) (list int)
      s without its leading decimal digits.
  skip_spaces ((s (list int))) (list int)
      s without its leading spaces, byte 32 only, not tabs or newlines.
  int_prefix ((s (list int)) (acc int)) int
      The number s starts with, in decimal, added to acc times ten per digit, so (int_prefix "42x" 0) is 42 and (int_prefix "x" 0) is 0.
  split_spaces ((s (list int))) (list (list int))
      The words of s, split at spaces, in order.
  is_space ((c int)) bool
      Whether c is a space, tab, newline, or carriage return.
  is_digit ((c int)) bool
      Whether c is one of the digits 0 to 9.
  is_lower ((c int)) bool
      Whether c is a lowercase letter a to z, or _: what may start a lowercase L0 name.
  is_upper ((c int)) bool
      Whether c is an uppercase letter A to Z.
  hex_val ((c int)) int
      The value of c as a hexadecimal digit, 0 to 15, in either case, or -1 if it is not one.
  float_sin ((x float)) float
      The sine of x, x in radians, within 1 ulp for |x| below 1647099, which is 2^20 times pi/2, and the one NaN past it, for an infinity, and for a NaN.
  float_cos ((x float)) float
      The cosine of x, x in radians, within 1 ulp for |x| below 1647099 and the one NaN past it, for an infinity, and for a NaN; see float_sin.

== io: Reading and writing lines, strings, and bytes, command-line arguments, files, devices' registers, and the traps of threads a kernel runs.
  read_line () (list int)
      The next line of standard input, including its newline if it has one.
  (data IoLine (IoLine (list int)) (IoEnd) (IoError int))
      A line read by next_line or file_next_line.
  next_line () IoLine
      The next line of standard input as an IoLine: (IoLine s) with its newline if it had one, (IoEnd) at end of input, or (IoError code) if a read failed.
  write_str ((s (list int))) int
      Writes every byte of s to standard output, in order, and returns 0.
  write_line ((s (list int))) int
      Writes s and then a newline to standard output, and returns 0.
  write_err ((s (list int))) int
      Writes every byte of s to standard error, and returns 0.
  (data IoBytes (IoBytes bytes) (IoReadFailed int))
      The rest of an input, read at once by read_input or file_read_all.
  read_input () IoBytes
      All of standard input that is left, as an IoBytes.
  args () (list (list int))
      Every command-line argument, in order, not counting the program's name.
  (data IoFile (IoFile int))
      An open file.
  (data (IoOpened E) (IoOpened IoFile) (IoFailed E (list int)))
      The result of opening a file: (IoOpened f), or (IoFailed fault why), where fault says which failure it was, as a case of E, and why says it in words, such as "no such file", for a message.
  (data OpenFault (OpenMissing) (OpenDenied) (OpenIsDirectory) (OpenFailed))
      Why opening a file to read failed: it does not exist, it may not be read, it is a directory, or anything else (spec section 6.3's -3, -4, -8, and -5).
  (data CreateFault (CreateDenied) (CreateNoDirectory) (CreateIsDirectory) (CreateFailed))
      Why creating a file, or opening one to append, failed: the file, or the directory it would be created in, may not be written; that directory does not exist; the name is a directory; or anything else (spec section 6.3's -4, -9, -8, and -5).
  (data (IoDone E) (Done) (NotDone E (list int)))
      The result of renaming, removing, flushing, or closing a file: (Done), or (NotDone fault why), where fault says which failure it was, as a case of E, and why says it in words, for a message.
  (is_done E) ((r (IoDone E))) bool
      Whether r is (Done).
  (data RenameFault (RenameMissing) (RenameDenied) (RenameIsDirectory) (RenameNoDirectory) (RenameCrossDevice) (RenameFailed))
      Why renaming failed: there is no file by the first name; either directory may not be written; the new name is a directory; the directory the new name would be in does not exist; the two are on different file systems; or anything else (spec section 6.3's -3, -4, -8, -9, -10, and -5).
  (data RemoveFault (RemoveMissing) (RemoveDenied) (RemoveIsDirectory) (RemoveFailed))
      Why deleting a file failed: there is no file by that name, which a program cleaning up may take as done; it may not be deleted; it is a directory; or anything else (spec section 6.3's -3, -4, -8, and -5).
  (data WriteFault (WriteNoSpace) (WriteBrokenPipe) (WriteNotOpen) (WriteFailed))
      Why bytes written to a file were lost, as flushing or closing it says: there was no space for them; it is a pipe whose reader had gone; it is not open for writing, as when it was already closed; or anything else (spec section 6.3's -6, -7, -2, and -5).
  open_in ((path (list int))) (IoOpened OpenFault)
      Opens the file at path for reading.
  open_out ((path (list int))) (IoOpened CreateFault)
      Creates the file at path, or empties it if it exists, and opens it for writing.
  open_appending ((path (list int))) (IoOpened CreateFault)
      Opens the file at path for writing at its end, creating it if it does not exist; what it already holds is kept.
  rename_file ((from (list int)) (to (list int))) (IoDone RenameFault)
      Gives the file at from the name to, replacing any file already there in one step, or says why not, with neither name changed.
  remove_file ((path (list int))) (IoDone RemoveFault)
      Deletes the file at path, in one step, or says why not, with the file still there; RemoveMissing means there was no such file, which a program cleaning up may take as done.
  open_in_bytes ((s (list int))) (IoOpened OpenFault)
      Opens a file that reads the bytes of s and then ends, held in memory.
  open_out_buffer () (IoOpened CreateFault)
      Opens a file in memory that keeps every byte written to it, for buffer_contents to return.
  buffer_contents ((f IoFile)) (list int)
      Every byte written so far to f, a file from open_out_buffer, or the empty list if f is not one.
  io_error ((code int)) (list int)
      What a negative result from an I/O builtin means, in words, for each code of spec section 6.3: -1 "end of input", -2 "not open in that direction", -3 "no such file", -4 "permission denied", -6 "no space left", -7 "the reader has gone", -8 "is a directory", -9 "no such directory", -10 "on another file system", and anything else "input or output failed".
  file_read_byte ((f IoFile)) int
      The next byte of f, or -1 at end of input, or another negative code if the read failed.
  file_write_byte ((f IoFile) (b int)) int
      Writes the byte b to f, and returns 0, or a negative code.
  file_write_str ((f IoFile) (s (list int))) int
      Writes every byte of s to f, and returns 0.
  file_write_bytes ((f IoFile) (b bytes) (i int) (j int)) int
      Writes bytes i up to but not including j of b to f, and returns 0, or a negative code.
  file_read_all ((f IoFile)) IoBytes
      The rest of f as an IoBytes, as read_input reads standard input.
  file_read_some ((f IoFile) (n int)) IoBytes
      The next piece of f, at least one byte and at most n, as (IoBytes b), with b empty only at the end, or (IoReadFailed code).
  file_read_line ((f IoFile)) (list int)
      The next line of f, as read_line reads standard input, so a failed read looks like end of input; file_next_line tells them apart.
  file_next_line ((f IoFile)) IoLine
      The next line of f as an IoLine, as next_line reads standard input.
  file_flush ((f IoFile)) (IoDone WriteFault)
      Delivers the bytes written to f so far, leaving it open, or says why some byte written to it could not be written.
  file_close ((f IoFile)) (IoDone WriteFault)
      Closes f, or says why some byte written to it could not be written.
  (data IoDevice (IoDevice int))
      A range of a device's memory, its registers, opened with open_device.
  (data DeviceOpened (DeviceOpened IoDevice) (DeviceFailed DeviceFault (list int)))
      The result of opening a device: (DeviceOpened d), or (DeviceFailed fault why), where fault says which failure it was and why says it in words.
  (data DeviceFault (DeviceMissing) (DeviceNoRoom))
      Why opening a device failed: the host has no device there, which under an operating system is every range; or no more can be open (spec section 6.12's -3 and -5).
  open_device ((base int) (len int)) DeviceOpened
      Opens the len bytes of device memory at address base, which must lie wholly within one of the machine's devices: on QEMU's virt board, those spec section 10.3 lists, such as the PL011 serial port's 4096 bytes at 0x09000000.
  close_device ((d IoDevice)) int
      Closes d, which open_device gave, once every access to it is complete, and returns 0: d is then no device, and its number may be given to a later open_device.
  device_read8 ((d IoDevice) (off int)) int
      The byte at off in d, 0 to 255.
  device_read16 ((d IoDevice) (off int)) int
      The 2 bytes at off in d, 0 to 65535, the lower address least significant.
  device_read32 ((d IoDevice) (off int)) int
      The 4 bytes at off in d, never negative, the lower address least significant: a 32-bit register.
  device_read64 ((d IoDevice) (off int)) int
      The 8 bytes at off in d as all 64 bits of an int, so negative when the top bit is set.
  device_write8 ((d IoDevice) (off int) (v int)) int
      Writes the low 8 bits of v at off in d, and returns 0.
  device_write16 ((d IoDevice) (off int) (v int)) int
      Writes the low 16 bits of v at off in d, and returns 0.
  device_write32 ((d IoDevice) (off int) (v int)) int
      Writes the low 32 bits of v at off in d, and returns 0.
  device_write64 ((d IoDevice) (off int) (v int)) int
      Writes all 64 bits of v at off in d, and returns 0.
  device_read_bytes ((d IoDevice) (off int) (n int)) bytes
      A copy of the n bytes at off in d, as bytes: for a range over memory, such as pages shared or given a device, not over registers, since each byte is read once, lowest first, but at widths the host chooses.
  device_write_bytes ((d IoDevice) (off int) (b bytes) (i int) (j int)) int
      Copies bytes i up to j of b into d from off, as device_read_bytes reads them, and returns 0.
  (data Trap (TrapCall int) (TrapMissing int) (TrapFault int int) (TrapInterrupt int))
      Why a thread came back from user_run: (TrapCall n), a system call with number n, which call_number reads; (TrapMissing va), a fault at the user address va where nothing is mapped, which a kernel answers by mapping a page there or ending the thread; (TrapFault why va), any other fault, with what the CPU said of it, its syndrome or cause, and the address; or (TrapInterrupt n), interrupt n, taken, which interrupt_done ends (spec section 6.14).
  trap_of ((c (array int))) Trap
      The trap the context c records, as a Trap, for the context user_run returned.
  call_number ((c (array int))) int
      The number of the system call the thread whose context is c made, from the register its CPU keeps it in: x8 on aarch64, a7 on riscv64.
  call_arg ((c (array int)) (k int)) int
      Argument k, 0 to 3, of the system call the thread whose context is c made, from the register its CPU passes it in: x0 to x3 on aarch64, a0 to a3 on riscv64.
  call_result ((c (array int)) (v int)) (array int)
      The context c with v as its system call's result, in the register its CPU returns one in, x0 on aarch64 and a0 on riscv64, so that the thread, run again with it, resumes after its call with that result.
  user_context ((pc int) (sp int)) (array int)
      A context for user_run that starts a thread at pc with its stack pointer at sp, every other register 0: an (array int) of the 104 words spec section 10.3 gives for each CPU.

== test: Assertions, golden files, and pseudo-random inputs for l0 test, which links this file.
  show_str ((s (list int))) (list int)
      s as an L0 string literal, with the escapes of spec section 2.2, so a value shown in a failure can be pasted back into a test.
  show_strs ((xs (list (list int)))) (list int)
      A list of strings as [s1, s2, ...], each shown as show_str shows it.
  pass ((name (list int))) int
      Reports the assertion name as passed, and returns 0.
  fail ((name (list int)) (got (list int)) (want (list int))) int
      Reports the assertion name as failed, showing got and want as given, and returns 1.
  fail_because ((name (list int)) (why (list int))) int
      Reports the assertion name as failed for the reason why, and returns 1.
  check_int ((name (list int)) (got int) (want int)) int
      0 if got equals want, and 1 otherwise, reporting both.
  check_bool ((name (list int)) (got bool) (want bool)) int
      0 if got equals want, and 1 otherwise, reporting both.
  check_true ((name (list int)) (ok bool)) int
      0 if ok is true, and 1 otherwise.
  check_str ((name (list int)) (got (list int)) (want (list int))) int
      0 if got and want hold the same bytes, and 1 otherwise, showing both as L0 literals and the first byte where they differ.
  check_strs ((name (list int)) (got (list (list int))) (want (list (list int)))) int
      0 if got and want are the same strings in the same order, and 1 otherwise, showing both.
  check_file ((name (list int)) (got (list int)) (path (list int))) int
      Compares got with the contents of the file at path, relative to the directory l0 test runs in, as check_str does.
  rand_next ((s int)) int
      The state after s in a pseudo-random sequence that is the same on every run, so a failing property test fails again.
  rand_below ((s int) (n int)) int
      A value from state s, in 0 to n - 1, for n above 0.
  rand_bytes ((s int) (n int)) (list int)
      n pseudo-random bytes, each 0 to 255, starting from state s.

l0 doc FILE shows one of these in full, l0 doc NAME one definition,
and l0 doc TEXT searches. Builtins such as read_byte are in the spec,
section 6: l0 spec.

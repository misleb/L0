== prelude: Lists of bytes: reversing, building output, comparing, decimal numbers, slicing lines and words, word tables, and character classes.
  rev_onto ((xs (list int)) (acc (list int))) (list int)
      xs reversed, in front of acc: (rev_onto "ab" "cd") is "bacd".
  rev ((xs (list int))) (list int)
      xs reversed.
  push ((chunk (list int)) (acc (list int))) (list int)
      Pushes chunk onto a reversed accumulator: acc with chunk's bytes in front, last byte first.
  append ((xs (list int)) (ys (list int))) (list int)
      xs followed by ys.
  length ((xs (list int))) int
      The number of elements of xs.
  list_eq ((xs (list int)) (ys (list int))) bool
      Whether xs and ys hold the same bytes in the same order.
  digits ((n int)) (list int)
      n in decimal, with a leading - if negative: (digits -42) is "-42".
  drop_n ((xs (list int)) (n int)) (list int)
      xs without its first n elements, or empty if it has fewer.
  starts_with ((s (list int)) (prefix (list int))) bool
      Whether s begins with prefix.
  take_line ((s (list int))) (list int)
      s up to but not including its first newline, or all of s if it has none.
  drop_line ((s (list int))) (list int)
      Everything after the first newline of s, or empty if it has none.
  skip_digits ((s (list int))) (list int)
      s without its leading decimal digits.
  skip_spaces ((s (list int))) (list int)
      s without its leading spaces, byte 32 only, not tabs or newlines.
  int_prefix ((s (list int)) (acc int)) int
      The number s starts with, in decimal, added to acc times ten per digit, so (int_prefix "42x" 0) is 42 and (int_prefix "x" 0) is 0.
  rev_strs_onto ((xs (list (list int))) (acc (list (list int)))) (list (list int))
      xs reversed, in front of acc, for a list of strings: rev_onto for (list (list int)).
  split_spaces ((s (list int))) (list (list int))
      The words of s, split at spaces, in order.
  any_eq ((n (list int)) (candidates (list (list int)))) bool
      Whether n is one of candidates.
  index_of ((n (list int)) (candidates (list (list int)))) int
      The position of n in candidates, counting from 0, or -1 if it is not there.
  is_space ((c int)) bool
      Whether c is a space, tab, newline, or carriage return.
  is_digit ((c int)) bool
      Whether c is one of the digits 0 to 9.
  is_lower ((c int)) bool
      Whether c is a lowercase letter a to z, or _: what may start a lowercase L0 name.
  is_upper ((c int)) bool
      Whether c is an uppercase letter A to Z.
  hex_val ((c int)) int
      The value of c as a hexadecimal digit, 0 to 15, in either case, or -1 if it is not one.

== io: Option and Result, for every type they hold; then reading and writing lines, strings, and bytes, command-line arguments, and files.
  (data (Option T) (None) (Some T))
      A value that may be missing: (Some x), or (None).
  (data (Result T E) (Ok T) (Err E))
      The outcome of something that can fail: (Ok x), or (Err e) saying why.
  read_line () (list int)
      The next line of standard input, including its newline if it has one.
  (data IoLine (IoLine (list int)) (IoEnd) (IoError int))
      A line read by next_line or file_next_line.
  next_line () IoLine
      The next line of standard input as an IoLine: (IoLine s) with its newline if it had one, (IoEnd) at end of input, or (IoError code) if a read failed.
  write_str ((s (list int))) int
      Writes every byte of s to standard output, in order, and returns 0.
  write_line ((s (list int))) int
      Writes s and then a newline to standard output, and returns 0.
  write_err ((s (list int))) int
      Writes every byte of s to standard error, and returns 0.
  (data IoBytes (IoBytes bytes) (IoReadFailed int))
      The rest of an input, read at once by read_input or file_read_all.
  read_input () IoBytes
      All of standard input that is left, as an IoBytes.
  args () (list (list int))
      Every command-line argument, in order, not counting the program's name.
  (data IoFile (IoFile int))
      An open file.
  (data IoOpened (IoOpened IoFile) (IoFailed (list int)))
      The result of opening a file: (IoOpened f), or (IoFailed why), where why says in words what went wrong, such as "no such file".
  open_in ((path (list int))) IoOpened
      Opens the file at path for reading.
  open_out ((path (list int))) IoOpened
      Creates the file at path, or empties it if it exists, and opens it for writing.
  open_appending ((path (list int))) IoOpened
      Opens the file at path for writing at its end, creating it if it does not exist; what it already holds is kept.
  rename_file ((from (list int)) (to (list int))) int
      Gives the file at from the name to, replacing any file already there in one step, and returns 0, or a negative code with neither name changed.
  open_in_bytes ((s (list int))) IoOpened
      Opens a file that reads the bytes of s and then ends, held in memory.
  open_out_buffer () IoOpened
      Opens a file in memory that keeps every byte written to it, for buffer_contents to return.
  buffer_contents ((f IoFile)) (list int)
      Every byte written so far to f, a file from open_out_buffer, or the empty list if f is not one.
  io_error ((code int)) (list int)
      What a negative result from an I/O builtin means, in words: -1 "end of input", -2 "not open in that direction", -3 "no such file", -4 "permission denied", and anything else "input or output failed".
  file_read_byte ((f IoFile)) int
      The next byte of f, or -1 at end of input, or another negative code if the read failed.
  file_write_byte ((f IoFile) (b int)) int
      Writes the byte b to f, and returns 0, or a negative code.
  file_write_str ((f IoFile) (s (list int))) int
      Writes every byte of s to f, and returns 0.
  file_write_bytes ((f IoFile) (b bytes) (i int) (j int)) int
      Writes bytes i up to but not including j of b to f, and returns 0, or a negative code.
  file_read_all ((f IoFile)) IoBytes
      The rest of f as an IoBytes, as read_input reads standard input.
  file_read_line ((f IoFile)) (list int)
      The next line of f, as read_line reads standard input, so a failed read looks like end of input; file_next_line tells them apart.
  file_next_line ((f IoFile)) IoLine
      The next line of f as an IoLine, as next_line reads standard input.
  file_flush ((f IoFile)) int
      Delivers the bytes written to f so far, leaving it open, and returns 0, or a negative code if any byte written to it could not be written.
  file_close ((f IoFile)) int
      Closes f, and returns 0, or a negative code if any byte written to it could not be written.

== test: Assertions, golden files, and pseudo-random inputs for l0 test, which links this file.
  show_str ((s (list int))) (list int)
      s as an L0 string literal, with the escapes of spec section 2.2, so a value shown in a failure can be pasted back into a test.
  show_strs ((xs (list (list int)))) (list int)
      A list of strings as [s1, s2, ...], each shown as show_str shows it.
  pass ((name (list int))) int
      Reports the assertion name as passed, and returns 0.
  fail ((name (list int)) (got (list int)) (want (list int))) int
      Reports the assertion name as failed, showing got and want as given, and returns 1.
  fail_because ((name (list int)) (why (list int))) int
      Reports the assertion name as failed for the reason why, and returns 1.
  check_int ((name (list int)) (got int) (want int)) int
      0 if got equals want, and 1 otherwise, reporting both.
  check_bool ((name (list int)) (got bool) (want bool)) int
      0 if got equals want, and 1 otherwise, reporting both.
  check_true ((name (list int)) (ok bool)) int
      0 if ok is true, and 1 otherwise.
  check_str ((name (list int)) (got (list int)) (want (list int))) int
      0 if got and want hold the same bytes, and 1 otherwise, showing both as L0 literals and the first byte where they differ.
  check_strs ((name (list int)) (got (list (list int))) (want (list (list int)))) int
      0 if got and want are the same strings in the same order, and 1 otherwise, showing both.
  check_file ((name (list int)) (got (list int)) (path (list int))) int
      Compares got with the contents of the file at path, relative to the directory l0 test runs in, as check_str does.
  rand_next ((s int)) int
      The state after s in a pseudo-random sequence that is the same on every run, so a failing property test fails again.
  rand_below ((s int) (n int)) int
      A value from state s, in 0 to n - 1, for n above 0.
  rand_bytes ((s int) (n int)) (list int)
      n pseudo-random bytes, each 0 to 255, starting from state s.

l0 doc FILE shows one of these in full, l0 doc NAME one definition,
and l0 doc TEXT searches. Builtins such as read_byte are in the spec,
section 6: l0 spec.
